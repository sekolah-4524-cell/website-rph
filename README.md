# Website RPH & Analisis

## Terbit di Render
1. Muat naik `index.html` dan `render.yaml` ke repositori GitHub baharu (di root repositori).
2. Log masuk https://dashboard.render.com dan pilih **New > Static Site**.
3. Sambungkan repositori GitHub.
4. Build Command: biarkan kosong. Publish Directory: `.`
5. Klik Deploy Static Site. Gunakan pautan `.onrender.com` yang diberikan Render.

## Penting
- Tiada log masuk atau pangkalan data.
- Fungsi Simpan Rekod menggunakan localStorage pada pelayar/peranti semasa sahaja. Data tidak dikongsi antara peranti.
- Gunakan Cetak / Simpan PDF untuk salinan sandaran.
- Elakkan memasukkan maklumat murid yang sensitif ke laman awam.
